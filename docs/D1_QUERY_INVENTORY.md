## Findings from the inventory
- No per-request query does an accidental full-table scan; the one secondary
  index serves every hot path (LOCALLY VERIFIED).
- No OFFSET pagination; no function-wrapped column in a WHERE that defeats
  the index, except `(unix % ?)=0` in `/audit`, which is applied after the
  index narrows to one symbol-day (LOCALLY VERIFIED).
- `SELECT *` appears in `toCsvRows` and `/export`; it returns
  `first_seen, updated_at, revisions` the consumers do not use. Costs bytes,
  not rows_read (CODE-DERIVED).
- The cost that matters is **rows visited × frequency** — see D1_ARCHITECTURE.md.
